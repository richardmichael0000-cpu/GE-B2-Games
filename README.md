# GE B2 Games

A collection of short, classroom-ready HTML activities for **Gold Experience B2 (2nd edition)**.

**Teaching purpose:** check understanding of a newly taught language point or strategy **before** the main Student's Book activity. These are not replacements for listening, reading, writing, or speaking practice.

## Game library

| Unit | Focus | Game | Time |
| --- | --- | --- | --- |
| 4: The Heart of the City | Listening preparation: synonyms and paraphrases | [Say It Differently!](unit-4/say-it-differently.html) | 5–7 minutes |
| 4: The Heart of the City | Use of English 2: prepositional phrases and sentence production | [Random Sentence Maker](https://wisers.my.canva.site/random-sentence-maker) (Canva) | 5–10 minutes |

Other reusable templates planned: Pelmanism, Grammar Auction, Gameshow Quiz, Group Sort, and Open the Box.

## How to run a game

Open [the game library](index.html), select a game, and click **Full screen**.

The Unit 4 game works offline once you save its HTML file. It needs no installation, account, server, external script, or internet connection.

### Unit 4 game: Say It Differently!

- 8 original practice examples on cities and public spaces.
- 2, 3, or 4 teams. Select a team by clicking its score panel.
- Correct answers award 10 points.
- After discussing why a tempting option is wrong, the teacher may award a 5-point explanation bonus.
- Reveal the answer without scoring if necessary.
- Keyboard: **1, 2, 3** to answer; **Enter** for the next question; **F** for full screen.
- The teacher clicks **Next question** to move forward; turns then rotate automatically.
- The practice examples are *not* excerpts from the copyrighted textbook recording and do not give away its answers.

### Unit 4 game: Random Sentence Maker

- Hosted on Canva and linked from the game library; it requires internet access.
- Generates a phrase, Unit 4 vocabulary word, topic, and communicative function.
- Students create original sentences; award up to 3 points for accurate phrase use, correct vocabulary use, and topic/function relevance.
- The Canva game is not stored as an HTML file in this repository.

## Publish using GitHub Pages

In this GitHub repository:

1. Select **Settings**.
2. In the sidebar, open **Pages** (under Code and automation).
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then **Save**.

Once GitHub finishes publishing, the site should be available at:
https://richardmichael0000-cpu.github.io/GE-B2-Games/

GitHub Pages may take a little time to publish a newly configured site. The live address is **not verified** until GitHub Pages reports a successful deployment.

## Design principles

- Large, legible text for a classroom TV.
- Teacher-controlled pacing, scoring, and answer reveal.
- A specific learning purpose for every game.
- Original question sets, with feedback that explains the reasoning.
- Standalone static HTML, CSS, and JavaScript.
